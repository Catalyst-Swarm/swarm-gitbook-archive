## Re-running the export

Create a GitBook API token, put `GITBOOK_TOKEN=...` in a `.env` file outside this repo, then run:

```
node --env-file=<path to .env> scripts/export.mjs <spaceId> [<spaceId> ...]
```

Space ids are in each `space.json`. Never commit the token.

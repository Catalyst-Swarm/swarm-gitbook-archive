# 1. Getting Started

### **Student Learning Targets (SLT)**

SLT 101 I can create a Discord Account

SLT 102 I can create a Cardano Wallet

SLT 103 I know how to join the SingularityNET Discord Server

SLT 104 I know how to sign in at the DFR3 Dework Server



***



### **1.1 Discord Account**

Discord is a communication platform which is used by SingularityNET and DeepFunding as a Community hub. [To Create a Discord Account, use this link](https://discord.com/). We recommend downloading the App on your PC device.&#x20;

If you already have a Discord account, you can comfortably skip this part and directly move forward\*



***



### **1.2 Cardano Wallet**

If you don't have a Cardano Wallet yet, we recommend [Typhon](https://typhonwallet.io/), [Eternl](https://eternl.io/) or [Game Changer](https://gamechanger.finance/) Wallets as the most advanced Cardano Light Wallets.&#x20;

There are many more wallets, and if you already have a Cardano wallet, there is no need to create a new wallet.



***



### **1.3 SingularityNET Discord Server**

You can join the official SingularityNET Discord Server [via this link](https://discord.com/invite/snet).&#x20;

If you are already on the Server, you are definitely already ahead and you can directly jump to the next part.



***



### **1.4 DFR3 Dework Server**

Once your Discord is set up and you joined the SingularityNET Discord Server, you can sign up on the DeepFunding Dework [via this link](https://app.dework.xyz/i/3Vjk410UuT8WRMKjBzg2ql). Make sure to sign in with your Discord Account. Once you are on the DeepFunding Dework, make sure to click the blue “follow” button on the top-right corner.

# 1.2 Cardano Wallets

### **1.2 Cardano Wallet**

If you don't have a Cardano Wallet yet, we recommend [Typhon](https://typhonwallet.io/), [Eternl](https://eternl.io/) or [Game Changer](https://gamechanger.finance/) Wallets as the most advanced Cardano Light Wallets.&#x20;

There are many more wallets, and if you already have a Cardano wallet, there is no need to create a new wallet.

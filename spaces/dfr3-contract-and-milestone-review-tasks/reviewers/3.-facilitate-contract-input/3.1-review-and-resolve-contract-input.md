# 3.1 Review & Resolve Contract Input

Once proposers start to submit their input on the Contracts, ensure that all required information is provided and answer in the Comments to any concern or change requests the proposers have added directly via the document.&#x20;

{% hint style="info" %}
If input on the contracts from proposers become overwhelming or hard to answer for yourself, look for support and advice from your review team members on the Review Discord Channel !
{% endhint %}

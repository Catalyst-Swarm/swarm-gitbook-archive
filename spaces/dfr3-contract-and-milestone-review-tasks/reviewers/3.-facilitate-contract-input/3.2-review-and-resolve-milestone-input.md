# 3.2 Review & Resolve Milestone Input

Proposers are able to adjust and modify their initial proposal milestones. You will have to check the initial Milestones from the awarded proposals and the Milestones submitted in the contract.



If changes to the milestones are made, ensure to check the table of the Milestone Change Request. Milestone changes have a certain tolerance of adjustment and can be accepted as long as Milestone changes do not differ too much from the initial Milestones.&#x20;

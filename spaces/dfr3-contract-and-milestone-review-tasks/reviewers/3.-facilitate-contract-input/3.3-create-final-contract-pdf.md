# 3.3 Create Final Contract PDF

Once all inputs from the proposers are approved, you can create a PDF document of the final version and upload it to this Google Drive: [https://drive.google.com/drive/folders/1kZRYkIUt1Cb8pc5xnRXRIbApu12M7O2f?usp=drive\_link](https://drive.google.com/drive/folders/1kZRYkIUt1Cb8pc5xnRXRIbApu12M7O2f?usp=drive_link)&#x20;



To create a PDF of the contract, follow these steps:

1\) Open the contract document

2\) Click the “File” item on the top-left corner of the document

3\) Select the “Download” item

4\) Select the “PDF Document (.pdf)” item

5\) Finally, upload the PDF file of the contract to this Google Drive: [https://drive.google.com/drive/folders/1kZRYkIUt1Cb8pc5xnRXRIbApu12M7O2f?usp=drive\_link](https://drive.google.com/drive/folders/1kZRYkIUt1Cb8pc5xnRXRIbApu12M7O2f?usp=drive_link)&#x20;



And thats it, the final PDF will be sent to the proposers via dropbox though which they will sign the contract, once they signed SingularityNET Foundation will add their signature marking the final point of this process. The proposal is now ready for being implemented by the awarded team

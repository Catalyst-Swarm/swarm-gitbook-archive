# Governance Framework

How the Document is built.

The current main Governance Framework document is an assembly of multiple documents, as such that each document chapter has its own document which is open to edit to contributors to add and change to the document.

![](https://1524382708-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FTeFJddoJo0HXvEut6ehK%2Fuploads%2F360jT1wXJLRfJp6pMChg%2FGOVFRAME.png?alt=media\&token=83f24493-a9ab-4679-a6af-70b29c71d7a7)

The main point here is to split up a larger document and to allow community members to focus their work and engagement on specific chapters, rather than the whole book at once.



Once changes on the side documents are submitted and reviewed, the new version gets updated to the main document
